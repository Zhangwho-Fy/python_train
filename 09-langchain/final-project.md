# 最终项目：本地文档问答机器人

把前面所有阶段串起来：**FastAPI 服务 + RAG + 流式回答 + 对话历史**。

## 需求

1. 启动时加载 `docs/` 目录构建向量索引（可复用 `rag_chat.py` 的 `build_chain`）；
2. `POST /api/chat`，请求体：

```json
{
  "question": "这个仓库的最终目标是什么？",
  "history": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

3. 响应用 `StreamingResponse` 流式返回，回答过程中附带来源文件列表（可选加分项）；
4. 模型和 key 全部走 `.env` 配置；
5. 错误处理：文档没加载、API 超时、空问题，都返回可读的错误信息而不是 500。

## 里程碑

- **M1**：命令行版 RAG 能回答 `docs/` 里的问题（第 4 步练习）；
- **M2**：FastAPI 非流式版本跑通（第 8 阶段 ex2 的升级版）；
- **M3**：流式 + 对话历史；
- **M4**：README 写清楚启动步骤，能给别人直接用。

## 验收清单

- [ ] 换个文档问它，回答引用到了对应内容
- [ ] 问文档里没有的问题，它说“不知道”而不是瞎编
- [ ] 回答是流式打印出来的（不是一次性返回）
- [ ] 第二轮提问能带上上一轮的上下文
- [ ] 杀进程重启后还能用（向量库持久化）

## 扩展方向（任选）

- 换本地模型（Ollama）实现完全离线；
- 加一个 `search_web` 工具让 Agent 可以联网；
- 给每个回答显示引用来源和相似度；
- 用 `langsmith` 记录每次调用方便调试。
