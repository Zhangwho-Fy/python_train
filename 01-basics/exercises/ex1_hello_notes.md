# ex1 hello 考点详解

## 题目回顾

问用户名字，打印 `你的名字是<名字>, 长度是<N>`，其中 N 是名字的字符数。

一句话流程：`input()` 拿字符串 → 存进变量 `name` → `len(name)` 算长度 → f-string 拼进 `print()`。

## 考点总览

| 考点 | 一句话 | 本题用法 |
| --- | --- | --- |
| `input()` | 从终端读一行，**总是返回字符串** | `name = input("输入名字:")` |
| 变量赋值 | 不用声明类型，直接 `x = ...` | `name = ...` |
| `len()` | 取字符串长度 | `len(name)` |
| f-string | `f"..."` 里用 `{}` 插变量 | `f"你的名字是{name}"` |
| `print()` | 打印并换行 | `print(...)` |
| `def main()` | 定义函数，调用前不会执行 | 把逻辑包进函数 |
| `if __name__ == "__main__":` | 只在“直接运行本文件”时执行 | 主入口惯用法 |

## 1. `input()`：读一行输入

```python
name = input("输入名字:")   # 先打印提示，再等用户回车
```

- 用户输入 `Alice` 后，`name` 的值是字符串 `"Alice"`。
- **返回的一定是字符串**：哪怕用户输入 `123`，拿到的也是 `"123"`（字符串），不是数字。这和 C++ 的 `std::cin >> x` 能按类型解析完全不一样——想当数字用必须自己转（见 ex2/ex3 的 `int()`）。
- 提示语可有可无；传进去的字符串会先打印出来，不自动带换行。

对比 C++：

| C++ | Python |
| --- | --- |
| `std::string s; std::cin >> s;` | `s = input()` |
| `std::getline(std::cin, s)` | `s = input()`（Python 只有“整行”这一种） |

## 2. 变量与 `len()`

```python
name = input("输入名字:")   # 不用声明，直接赋值
n = len(name)              # 字符串长度
```

- Python 变量没有类型声明，也没有 `auto`——赋值即存在。
- `len()` 对字符串返回字符个数；中文按“字符”计，`len("张三") == 2`。
- 字符串是不可变的；`len()` 只是读取，不会改 `name`。

## 3. f-string 格式化

```python
print(f"你的名字是{name}, 长度是{len(name)}")
```

- `f` 前缀表示“格式化字符串”，花括号 `{}` 里可以直接写变量、表达式、甚至函数调用。
- 等价写法（都不如 f-string 常用）：

```python
print("你的名字是" + name + ", 长度是" + str(len(name)))   # 手动拼接，要自己 str()
print("你的名字是{}, 长度是{}".format(name, len(name)))    # 老式 format
```

对比 C++：`std::format("你的名字是{}, 长度是{}", name, len(name))`，概念一样。

## 4. 函数与主入口

```python
def main() -> None:      # 定义函数：现在只是“登记”，不会执行
    name = input("输入名字:")
    print(f"你的名字是{name}, 长度是{len(name)}")

if __name__ == "__main__":
    main()               # 直接运行本文件时，才真正调用
```

- Python 脚本从上往下执行；`def` 只定义函数，函数体要等被调用才跑。
- `if __name__ == "__main__":`：直接 `python3 ex1_hello.py` 时成立；如果别人 `import` 这个文件，就不会自动跑，方便复用。

## 5. 易错点清单

1. **忘掉 `input()` 返回字符串**：`len("123") == 3`，但 `len(123)` 直接 `TypeError`。
2. **f-string 忘写 `f` 前缀**：`"你的名字是{name}"` 会原样打印 `{name}`。
3. **缩进不一致**：函数体必须统一缩进（约定 4 空格）。
4. **直接在主入口外写逻辑**：被 import 时也会执行，养成写 `main()` 的习惯。
5. 文件名、函数名、变量名都用小写加下划线，别用驼峰（社区约定，不是语法要求）。

## 6. 变式练习

- 同时问姓名和年龄，打印一句话自我介绍。
- 输入前先 `input(...).strip()` 去掉首尾空格，再判断是否为空。
- 把 `main()` 改成返回 `f"..."` 字符串，`print` 只放在调用处。
