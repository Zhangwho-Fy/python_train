第 0 节运行与变量

打开终端输入 python3 -i 进入交互模式，里面输一行执行一行——这就是最快的学习方式。C++ 的入口是 main，Python 的入口是“文件第一行”。

Hello World

#include <iostream>
int main() {
    std::cout << "hello\n";
    return 0;
}
print("hello")

动态类型：变量不声明

int x = 3;
x = "hi";   // 编译错误
x = 3
x = "hi"    # 合法：类型跟着对象走
print(type(x))  # <class 'str'>

格式化输出

std::string name = "alice";
std::cout << "hi " << name
          << ", len=" << name.size() << "\n";
name = "alice"
print(f"hi {name}, len={len(name)}")
# f-string 里的 {} 就是表达式槽
  • None ≈ C++ 的 nullptr，是独立类型。
  • id(obj) ≈ 取对象地址；a is b 比身份，a == b 比内容。
  • 布尔是大写 True / False；5 / 2 == 2.5，5 // 2 == 2。
对应练习：01-basics/exercises/ 的 ex1 hello 和 ex4 word_frequency。

第 1 节容器

Python 的容器是语言核心：list（≈ vector）、dict（≈ map）、tuple、set，还能互相嵌套。它们都是对象，不需要模板参数。

list vs std::vector

std::vector<int> v{1, 2, 3};
v.push_back(4);
std::cout << v[0] << " " << v.size();
v = [1, 2, 3]
v.append(4)
print(v[0], len(v))   # 1 4
print(v[-1])          # 4，负下标从右往左

dict vs std::map

std::map<std::string, int> m;
m["a"] = 1;
m = {"a": 1}
m["b"] = 2
print(m.get("a", 0))   # 带默认值的查找
print(m.get("zz", 0))  # 0，不抛异常

切片 ≈ 迭代器区间

// 取 v[1] 到 v[2]
std::vector<int> sub(v.begin() + 1,
                     v.begin() + 3);
sub = v[1:3]     # 半开区间 [1, 3)
rev = v[::-1]    # 反转，最常用的技巧
tail = v[-2:]    # 最后两个元素

列表推导式：一行版 transform + filter

squares = [x * x for x in range(10) if x % 2 == 0]
# 读作：对 0..9 中每个偶数 x，放进 x*x
# 等价 C++ 的 copy_if + transform 再拼接
  • tuple 不可变：a, b = (1, 2) 直接解包，函数多返回值靠它。
  • set 去重：unique = list(set(xs))。
  • 字典/集合是哈希表，key in d 是 O(1)。
  • append 摊还 O(1)；insert(0, x) 是 O(n)，别当头插用。
对应练习：ex5 calculator（字符串 split + 容器）与 02 阶段 ex4 推导式专场。

第 2 节控制流

没有大括号、没有 for(;;) 三件套。缩进即块，for 只会遍历。

if / elif

if (x > 0) { ... }
else if (x < 0) { ... }
else { ... }
if x > 0:
    ...
elif x < 0:
    ...
else:
    ...

for 循环

for (int i = 0; i < 10; ++i)
    std::cout << i;
for (auto& x : v)
    std::cout << x;
for i in range(10):        # 0..9
    print(i)
for x in v:                # 遍历元素
    print(x)
for i, x in enumerate(v):  # 下标 + 元素
    print(i, x)
for i in range(2, 10, 3):  # 2,5,8
    print(i)

while 与三目

while (n > 0) { ... }
int m = cond ? a : b;
while n > 0:
    ...
m = a if cond else b
  • 没有 switch：用 if/elif 或字典映射。
  • 缩进必须一致（统一 4 空格）；IDE 会自动处理，别用 Tab 混空格。
  • 循环里的 break / continue 和 C++ 一样。
对应练习：01 阶段 ex2 fizzbuzz、ex3 猜数字。

第 3 节函数与模块

定义与默认参数

int add(int a, int b = 1) {
    return a + b;
}
def add(a: int, b: int = 1) -> int:
    return a + b

add(3)      # 4
add(3, 5)   # 8
add(b=5, a=3)  # 关键字参数，顺序随意

lambda

auto twice = [](int x) { return x * 2; };
twice = lambda x: x * 2
evens = [x for x in xs if x % 2 == 0]  # 常用场景其实是推导式

*args / **kwargs

def log(msg, *args, **kwargs):
    # args 是位置参数元组，kwargs 是关键字参数字典
    print(msg, args, kwargs)

log("hi", 1, 2, level="info")
# hi (1, 2) {'level': 'info'}

import ≈ #include

#include <vector>
using std::vector;
import math
from collections import Counter
import numpy as np   # 起别名 ≈ using
# 被 import 时不执行，直接运行才执行：
if __name__ == "__main__":
    main()
对应练习：02 阶段 ex1 my_map_filter、ex3 stats 模块。

第 4 节文件与异常

读文件：with ≈ RAII

std::ifstream f("a.txt");
std::string line;
while (std::getline(f, line)) { ... }
with open("a.txt", encoding="utf-8") as f:
    for line in f:      # 逐行，不整读进内存
        ...
# 离开缩进块自动 close

异常

try {
    throw std::runtime_error("boom");
} catch (const std::exception& e) {
    std::cout << e.what();
}
try:
    raise ValueError("boom")
except ValueError as e:
    print(e)
finally:
    ...  # C++ 没有的 finally，总是执行

JSON ≈ nlohmann/json

auto j = nlohmann::json::parse(s);
int score = j["score"];
import json
data = json.loads(s)          # 字符串 → Python 对象
score = data["score"]
out = json.dumps(data, ensure_ascii=False, indent=2)  # 中文不转义
  • 先抓具体异常（FileNotFoundError），别用裸 except:。
  • 读写都写 encoding="utf-8"，跨平台不踩坑。
对应练习：04 阶段 ex1 词频、ex2 JSON 清洗、ex3 logger。

第 5 节类

基本类

class Point {
public:
    Point(int x, int y) : x_(x), y_(y) {}
    int x_, y_;
};
class Point:
    def __init__(self, x: int, y: int):
        self.x = x          # 没有成员声明，直接赋值
        self.y = y

运算符重载 → 魔术方法

Point operator+(const Point& a,
                const Point& b) {
    return {a.x_ + b.x_, a.y_ + b.y_};
}
def __add__(self, other):
    return Point(self.x + other.x, self.y + other.y)

def __repr__(self):
    return f"Point({self.x}, {self.y})"

property ≈ getter/setter

class Account:
    def __init__(self, balance):
        self._balance = balance

    @property
    def balance(self):
        return self._balance
    # 读 acc.balance 走这里；想只读就不写 setter

dataclass：自动生成样板

from dataclasses import dataclass

@dataclass
class Student:
    name: str
    score: int
    # 自动得到 __init__ / __repr__ / __eq__
  • self ≈ this，但必须显式写在参数表里。
  • 没有 private：_x 是约定“别碰”，__x 会名称修饰。
  • 继承用 class B(A):，调基类构造用 super().__init__(...)。
  • pydantic 是“带运行时校验的 dataclass”，LangChain 全家靠它。
对应练习：05 阶段 ex1 Vec2d、ex4 dataclass vs pydantic。

第 6 节进阶特性

装饰器：包装函数

import functools, time

def timer(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        result = fn(*args, **kwargs)
        print(f"{fn.__name__} 耗时 {(time.perf_counter()-t0)*1000:.1f}ms")
        return result
    return wrapper

@timer
def work():
    ...
# @timer 等价于 work = timer(work)

生成器：惰性序列

def lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line   # 用一次算一次，不占内存

for line in lines("big.txt"):
    ...

上下文管理器：with

from contextlib import contextmanager

@contextmanager
def timed():
    t0 = time.perf_counter()
    try:
        yield
    finally:
        print(f"耗时 {(time.perf_counter()-t0)*1000:.1f}ms")

with timed():
    work()

async 速览（对应 C++20 coroutine）

import asyncio

async def fetch(url):
    await asyncio.sleep(1)   # await ≈ co_await
    return url

results = asyncio.run(
    asyncio.gather(fetch("a"), fetch("b"), fetch("c"))
)
